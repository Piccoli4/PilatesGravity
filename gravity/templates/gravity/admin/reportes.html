    Cómo se calculan estos números
    • Ocupación: reservas fijas activas sobre el cupo de cada clase. Es una foto de hoy y no cambia con el período elegido.
    • Reservas nuevas y bajas: reservas creadas o dadas de baja dentro del período seleccionado.
    • Asistencia estimada: se cuentan las clases que le tocaban a cada reserva activa dentro del período y se descuentan las ausencias avisadas y las faltas sin aviso registradas por el estudio.
    • Recuperos: reservas de fecha única tomadas dentro del período.
      • {% if puede_ver_pagos %}
    • Ingresos: pagos confirmados con fecha dentro del período. La comparación es contra los {{ dias_periodo }} día{{ dias_periodo|pluralize }} anteriores.
    • Facturado: deudas mensuales generadas por el sistema según el plan de cada cliente.
      • {% endif %}
